65-### Strict parsing and partial trees
66-
67-The default parse methods preserve tree-sitter's partial-tree behavior. If a
68:timeout, cancellation flag, token-source EOF, or parser safety limit stops
69-the parse early, the returned tree records the stop reason and the error
70-stays nil. This is useful for editors and diagnostics, where a partial tree
71-still has value.
72-
73-Use strict methods when partial output should fail a request:
74-
75-```go
76-parser.SetTimeoutMicros(50_000)
77-
78-tree, err := parser.ParseStrict(src)
79-if errors.Is(err, gotreesitter.ErrParseStoppedEarly) {
80-    fmt.Println(tree.ParseStopReason())
81-}
82-```
83-
84-Strict variants are available for full parse, incremental parse, token-source
85-parse, factory parse, `ParseWith`, and `ParserPool`.
